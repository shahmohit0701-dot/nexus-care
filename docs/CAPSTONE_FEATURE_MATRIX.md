# Capstone Feature Matrix

| Proposal area | NEXUS implementation |
|---|---|
| Patient intake | Conversational patient-side AI intake |
| NER / terminology | Lightweight symptom entity extraction with aliases |
| Negation | Negated symptom detection |
| Duration/severity | Regex duration + severity extraction |
| EHR | PostgreSQL/SQLite patient profile + FHIR-style export |
| ML triage | XGBoost disease/symptom model + ESI-style risk engine |
| ESI | Levels 1–5 with confidence and reasons |
| Clinical dashboard | Live hospital queue and emergency feed |
| RBAC | Patient / clinician / admin demo roles |
| AI assistant | Conversational intake and explanation output |
| Emergency | Emergency button, browser location, simulated ambulance |
| Camera | Guardian Vision browser camera module |
| Interoperability | FHIR-style Bundle resources |
| Data | Synthetic disease/symptom training data generated from curated seed profiles |
