NEXUS CARE v6 — LEVEL-UP BUILD

1. Extract this ZIP into a new folder (not inside OneDrive if Windows Smart App Control is aggressive).
2. Right-click the ZIP > Properties > if you see Unblock, tick it > Apply, BEFORE extracting.
3. Open the extracted NEXUS-CARE folder.
4. Double-click start_demo_8040.bat.
5. Open http://127.0.0.1:8040 if it does not open automatically.

IMPORTANT SAFETY NOTE
This is an academic prototype. It is not a medical device and does not diagnose disease. Model metrics are based on synthetic/generated educational data, not clinical validation. Emergency dispatch is simulated. Browser camera access is controlled by Chrome/Edge; a web page cannot legitimately bypass browser camera permission.
